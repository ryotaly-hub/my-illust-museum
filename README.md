# my-illust-museum

イラストが発表したくてウズウズしてる人の「自己満専用美術館」です。

## 構成

- 種類: Express（Node.js）の Web アプリ／API
- デプロイ先: なし

## 使い方

- **起動**: `npm start` → http://localhost:3001/
- **テスト**: `npm test`（= `bash test.sh`）。サーバーを自動で起動し、curl でエンドポイントを叩いて期待値と比較する。`curl` と `jq` が必要。
  - **注意**: `test.sh` は最初にポート 3001 のプロセスを `kill -9` する。
  - 新しいエンドポイントを追加したら、`test.sh` に `assert_eq` を追加する。

## 画面の使い方

- アクセスすると、まずオープニング：最新の作品（最大 5 枚）が画面の奥から手前へ通り過ぎ、タイトル、「入館する」ボタンの順に現れる（作品がないときはタイトルとボタンだけ）。画面のクリックか Esc でスキップできる。タブを開いている間は 1 回だけ表示する。
- 入館すると、最新の作品が正面から大きく表示される（下に作品名・日付・説明）。
- 右の「→ 過去へ」を押すと、美術館の廊下（3D）に戻り、奥＝過去の作品の方へ進む。左の「← 未来へ」で入口＝新しい作品の方へ戻る。
- 廊下では作品が左右の壁に交互に額装されて斜めに見える。絵をクリックすると、その絵の正面に向き直って大きく表示する。
- 正面表示の絵をもう一度クリックすると、絵が画面に収まる最大の大きさまで拡大する（額は画面からはみ出してもよいが、絵ははみ出さない）。拡大中はタイトルだけを表示し、もう一度クリック（または Esc）で正面表示に戻る。
- 操作: 矢印キー（→/↑ で過去へ、←/↓ で未来へ）、マウスホイール、スワイプ（左か上で過去へ）、Enter で正面表示→拡大、Esc で一つ前の表示（拡大→正面→廊下）に戻る。

## 作品の登録（自分専用）

1. 画面右下の歯車ボタンを押し、パスワードを入れる（初期パスワードは `0000`。登録画面の下の「パスワードを変更する」で変えられる）。
2. 画像をドロップ（またはクリックして選択）し、タイトル・説明・作成日時を入力して「登録する」。
3. 登録した作品は、新しい順の一覧（サムネイル付き）に入る。左端の ⋮⋮ をドラッグすると並べ替えられ、その順番が美術館の並び（左＝新しい）になる。「編集」でタイトル・説明・作成日時・画像を直せる（画像は差し替えたいときだけ選び直す）。「削除」で取り下げ。
4. 「閉じる」と美術館に反映される。

- 画像は `assets/works/` に、作品データは `data/works.json` に保存される（どちらも git 管理外。リポジトリには上がらない）。長辺 2400px を超える画像は登録前に縮める（GIF はそのまま）。
- 額の窓はすべて白銀比（横長の絵は √2 : 1、縦長の絵は 1 : √2）。正方形の絵は横長の額になる。絵は切り取らずに収め、余白はマット（台紙）になる。
- 額は `public/frames/` の 10 種類（縦長用 5・横長用 5）から、登録時に絵の向きに合わせてランダムに選ばれ、作品に保存される。
- 画像が見つからない作品は「画像準備中」の額として表示される。
- クローンした直後は作品 0 件から始まる。前の環境の作品は「登録情報の読込み」で引き継ぐ。`data/works.sample.json` はテスト用のサンプル（画像なし）。
- **別の環境への引き継ぎ**：登録画面の「登録情報の書出し」で、作品の情報と画像をまとめた 1 つのファイル（`my-illust-museum-日付.json`）がダウンロードされる。移した先で「登録情報の読込み」からそのファイルを選び、「すべて置き換える」か「今の作品に追加する」（同じ作品は飛ばす）を選ぶ。パスワードは含まれないので、移した先では初期パスワード `0000` で入る。読み込めるファイルは 500MB まで。
- 変更したパスワードは `data/admin.json`（git 管理外）にハッシュで保存される。忘れたらこのファイルを消すと `0000` に戻る。

## 資料の保存場所

- `docs/` — 仕様・メモ・参考資料（中身は .gitignore 済み。リポジトリには上がらない）
- `assets/` — 画像などの素材（中身は .gitignore 済み。リポジトリには上がらない）

## 秘密情報

- 値は `.env`（`.gitignore` 済み）に置く。コードへのハードコードやコミットはしない。

| 名前 | 用途 | GitHub Actions |
|---|---|---|
| `API_KEY` | GeminiのAPI呼び出し | Secrets に登録して使う |

## 初期設定のチェックリスト

- [ ] `cp .env.example .env` を実行し、`.env` に秘密情報の値を設定する
